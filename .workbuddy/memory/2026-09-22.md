# 2026-09-22 WenQwen2 项目笔记

## 项目结构
- .NET 8.0 Windows WinForms 控制台混合项目（WenQwen/WenQwen.csproj）。
- 模型路径固定：`E:\wqz\model\qwen2.5-7b-instruct-1m-q4_k_m.gguf`（LocalChatAssistant 与 VisionAGI 共用）。

## 入口点（重要）
- 唯一有效入口是 `LocalChatAssistant.cs` 里的 `static async Task Main`（namespace QwenConsole）。
- `Program.cs` 的入口被错写成 `Main2`，并非有效入口，不要改它成 Main，否则会与 LocalChatAssistant.Main 冲突报 CS0017（多个入口点）。
- 若想让 GUI (VisionAGI) 成为启动项，需要改 Program.cs 的 `Main2`→`Main` 并去掉 LocalChatAssistant 的 Main。

## 曾发生的问题

- 已删除的“多余”实验程序（各带独立 namespace 的 class Program）：Qwen35ScreenClick.cs、QwenConsole2~5.cs。
